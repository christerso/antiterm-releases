# AntiTerm 1.0.0

AntiTerm is a terminal for Windows, macOS and Linux. Your programs keep running when you close the window, and your tabs and splits come back when you open it again. This is the first release.

- Programs keep running when you close the window, and open again where you left them.
- Tabs, splits and a quick terminal on a global key.
- Find as you type in the scroll-back.
- antish, its own command line, with AntiTerm's own everyday commands.
- Ctrl+click on links and file paths, and secrets hidden from AI agents.
- Text can always be selected with a drag, even while a program such as vim or tmux takes the mouse; a click still goes to the program.
- An optional scene behind the splits, across every window and monitor: a planetarium of the real solar system (the planets where they are now, NASA's maps, a camera that orbits the sun) or a dark deep sea with creatures that drift past and glow.
- Notes and job messages from AntiMail show in the notepad as readable Markdown, without setting anything up.
- After a crash, a hang or a stuck part, AntiTerm offers a report the next time it starts; the report can be sent automatically.
- Rune, our script language for builds and deployments, comes with it.
- Fixed after our security review: a file name printed by a program can no longer run a command when you click it.
