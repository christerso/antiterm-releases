# AntiTerm 1.0.1

- A new scene behind the splits shows a black hole, its glowing disk bending the light around it, with a small world and galaxies beyond.
- On Windows and Linux, Ctrl+C copies selected text and otherwise reaches the program as before, unless a setting sends it to the program always; on a Mac, Cmd+C copies.
- Claude Code running in AntiTerm runs its commands in antish, AntiTerm's own shell, instead of Git Bash.
- In the planetarium, the planets are lit from the side when the camera stays with one, Saturn shows its ringlets in their real colours, and the sun's face can be seen from close by.
- In the deep sea, the creatures swim where the lamps reach them, so they can be seen.
- Fixed: on Windows, a scene behind the splits no longer keeps a processor core busy with some graphics drivers.
